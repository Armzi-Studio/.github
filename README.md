# Armzi-Studio / .github

This repository contains organization-wide default configurations, community health files, issue/PR templates, and the organization profile README for **[Armzi-Studio](https://github.com/Armzi-Studio)**.

## 📁 Repository Structure

```
.github/
├── profile/
│   └── README.md                  # Organization Profile Landing Page (shown on github.com/Armzi-Studio)
├── .github/
│   ├── ISSUE_TEMPLATE/
│   │   ├── bug_report.yml         # Structured GitHub Issue Form for bug reports
│   │   ├── feature_request.yml    # Structured GitHub Issue Form for feature suggestions
│   │   └── config.yml             # Global issue templates configuration & contact links
│   ├── PULL_REQUEST_TEMPLATE.md   # Default Pull Request Template for all organization repos
│   ├── CONTRIBUTING.md            # Default Organization Contribution Guidelines
│   ├── SECURITY.md                # Default Security Policy & Vulnerability Disclosure
│   └── CODE_OF_CONDUCT.md         # Organization Code of Conduct (Contributor Covenant)
└── README.md                      # Repository overview
```

## ⚙️ How It Works

GitHub automatically applies files in this special `.github` repository to all public and private repositories in the **Armzi-Studio** organization unless overridden at the individual repository level:

1. **Profile README (`profile/README.md`):** Automatically rendered on the organization's public landing page at `https://github.com/Armzi-Studio`.
2. **Issue Forms & Templates (`.github/ISSUE_TEMPLATE/*`):** Provided as standard issue templates when contributors create issues in any repository.
3. **Pull Request Template (`.github/PULL_REQUEST_TEMPLATE.md`):** Automatically populates the PR description for new pull requests across all repositories.
4. **Community Health Files (`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`):** Shown in the sidebar and contributor workflows across all repositories.
