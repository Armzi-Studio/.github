## 🎯 Core Focus Areas

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ Systems & Rust  │   │  Full-Stack &   │   │  IoT, Firmware  │
│  High-Perf Core │──▶│ Cross-Platform  │──▶│  & Industrial   │
│ Tauri / Micro-S │   │ Next.js/React/Go│   │ Modbus / ESP32  │
└─────────────────┘   └─────────────────┘   └─────────────────┘
```

- 🦀 **Systems & Desktop Applications:** High-performance software engineering using Rust, Tauri 2, Go, and C/C++.
- ⚡ **Industrial Simulation & IoT:** Protocol automation (Modbus RS-485, CAN, MQTT), industrial hardware simulations, and embedded devices (ESP32/CYD).
- 💻 **Modern Full-Stack Platforms:** Scalable web & mobile ecosystems built with React 19, Next.js, Flutter, Laravel, and GraphQL/REST APIs.
- ☁️ **DevOps & Infrastructure:** Cloud-native architecture, containerization (Docker, Kubernetes), CI/CD pipelines, and robust automation tooling.
